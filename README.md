# 02:17, 마지막 점검

등대 렌즈가 사라진 밤의 전시실을 조사하는 한국어 단편 추리게임입니다. 휴대폰 브라우저에서 열고 홈 화면에 추가하면 앱처럼 쓸 수 있습니다. 한 번 연 뒤에는 오프라인에서도 열립니다.

플레이: https://garlicb.github.io/0217-last-inspection/

- 안드로이드 크롬: 시작 화면의 「앱으로 설치」, 또는 메뉴(점 세 개) → 「앱 설치」
- 아이폰 사파리(iOS 15.4 이상): 공유 단추 → 「홈 화면에 추가」

외부 서버와 통신하지 않습니다. 진행 기록은 그 기기에만 저장됩니다.

3D 화면은 three.js(MIT 라이선스)로 만들었습니다.
